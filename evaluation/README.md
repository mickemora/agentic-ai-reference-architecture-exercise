# Evaluation Harness

The harness will evolve from deterministic assertions to trace-aware agent evaluation.

## Planned dimensions

- Decision accuracy
- Retrieval relevance and recall
- Citation correctness
- Tool selection and argument accuracy
- Groundedness and abstention
- Guardrail effectiveness
- Latency, token use, tool calls, and estimated cost

`golden_dataset.json` is versioned with the code so architectural changes can be compared against a stable behavioral contract. Synthetic cases only.
